# 悦己志 · 女生日常美学与灵感实验室

面向年轻女生与女大学生的纯前端轻量级综合网页应用，无需后端即可运行，可直接上传至 Cloudflare Pages 或 GitHub Pages 托管。

## 包含模块
1. **审美风格自测**：10 道生活化穿衣审美题，输出个人风格、显白配色卡与穿搭避雷，支持一键截图海报模式。
2. **情绪盲盒与今日一签**：每日灵感签文抽取、幸运色/幸运小物与“烦躁清零”轻量解压按钮。
3. **买前必看决策工具**：护肤成分叠加冲突自查器 + 预算/场景好物筛选清单（已预留推广口令/链接位）。
4. **高颜值自律工作台**：番茄钟、自定义倒计时与 30 天微习惯打卡（通过浏览器 localStorage 自动保存）。
5. **周末灵感盲盒**：按预算、同行对象与心情抽取周末出行方案、拍照技巧与穿搭公式。

## 部署方式
直接将本文件夹拖入 Cloudflare Pages（Direct Upload）或上传至 GitHub 公开仓库开启 Pages 即可生成长期免费访问链接。
